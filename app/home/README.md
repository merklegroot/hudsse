# Machine Information Page

A dashboard that displays comprehensive information about your system's hardware, operating system, and network configuration.

### Left Panel - System Overview

The left side features two key visual indicators:

- **OS Type** - Shows your operating system (Linux, Windows, macOS, etc.) with a recognizable icon
- **Virtualization Status** - Displays whether you're running on bare metal, in a virtual machine, Docker container, or other virtualization environment, complete with a visual icon

### Right Panel - Detailed System Information

The main content area displays your system details in an easy-to-read grid:

- **Machine Name** - Your computer's hostname
- **Local IP Address** - Your network IP address
- **Machine Model** - The product name/model of your hardware (can be refreshed manually)
- **CPU Model** - Your processor information
- **Distro Flavor** - Your Linux distribution (if applicable)
- **Kernel Version** - Your operating system kernel version
- **Motherboard** - Your motherboard name/model

### Bottom Section

At the bottom of the page, you'll find a detailed machine state viewer that provides additional technical information about your system.

## Layout

The page is designed to work well on both desktop and mobile devices:

- On larger screens, information is displayed in a two-column grid
- On smaller screens, the layout automatically adjusts to a single column for easier reading
- The OS and virtualization panels remain visible on the left side for quick reference
