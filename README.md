# HudApp SSE

An SSE version of the HUD app.  
Right now, it mostly deals with managing .NET installations.

## Icons

This project uses icons from [react-icons](https://react-icons.github.io/react-icons/), which includes:
- **Simple Icons** (Si*) - Brand icons (MIT License)
- **Font Awesome** (Fa*) - General purpose icons (CC BY 4.0 License)
- **Heroicons** (Hi*) - UI icons (MIT License)
- **Devicons** (Di*) - Development icons (MIT License)

Icons are used to visually represent CPU vendors, virtualization types, and operating systems throughout the application.
